本次改动（v0.17.1 → v0.17.2）

  • 「线条」「效果」那一格原本是可折叠标题栏（左标题 + 右侧 ▸ + 一条 border-bottom）， 现在和「填充」一样换成一条 1px 分割线，内容直接排开。
  • 标题栏没了不影响功能：两个分组本来就默认展开（open），内容一直可见。 「线条」二字仍在下面那行的勾选框标签上；「效果」这两个字会一起消失（它只出现在标题栏里，组内 4 个勾选框没有同名字样）—— draw.io 原版这一组本来也不带标题，如果你希望留住「效果」二字，说一声我把它挂到某个勾选框或加个小标签。
  • 不透明度那一行移进了线条组。它原来挂在分组之外（所以现在你能看到它上方那条线就是标题栏分区的 border-bottom）。 改扁平后若还留在组外，它会因为 .drawio-fmt-row:last-child { margin-bottom: 0 } 紧贴上面的线型控件、一点缝都没有。
  • 三条分割线间距完全一致：上 11px / 下 10px。首组（紧接配色轮播那条）上方不叠加 —— 否则 .drawio-fmt-palette 的 margin-bottom: 11px 会和新加的 margin-top: 11px 叠成 22px， 第一条线的间距会明显比后两条宽。
  • 分割线自身仍复用 .drawio-fmt-divider，只覆盖边距； 文本 / 排列面板里那条分割线保持 12px 原样（用 .drawio-fmt-flat > .drawio-fmt-divider 限定作用域）。

装进 vault 后建议顺手验一下

  • 配色区下面应看到 3 条淡灰细线，彼此的上下间距看起来一样宽（不要第一条明显更宽、也不要两条线挨在一起成双线）。
  • 「线条」勾选框、「不透明度」两行之间不要贴死；「不透明度」下面是最后一条线，线下面是 4 个效果勾选框。
  • 色块应是 3:2 的方块；箭头 / 圆点 / 色块都应是透明底、无灰块、无内描边；三组里的勾选框能正常切换。
  • 切到「文本」「排列」面板，那里的分区标题栏（字体 / 段落 / 对齐…）应保持原样可折叠，分割线仍是较宽的 12px 间距。
