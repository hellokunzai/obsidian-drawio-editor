## 修复拖拽预览"什么都不显示"（v0.4.5）
- 用户实测 v0.4.4：拖动时预览完全空白（应只显示图形轮廓）。
- **根因**：Electron/Chromium 构建不会捕获**离屏元素**（top/left 为负的大值）作为 `setDragImage` 源——上版那个 `-1000px` 的 div 直接被忽略，于是啥也不显示。
- **关键点**：`setDragImage` 在**调用瞬间同步**把元素截成位图。正确做法：先把幽灵图放在屏内可见位置（用 `e.clientX/Y`）完成捕获，调用完立刻移出视口；之后位图已生成，移走不影响预览。
- 改用 `HTMLCanvasElement` 画轮廓最稳：透明背景 + `ctx.stroke(new Path2D(shape.icon))`（shape.icon 是 SVG path 串，24×24 视口，缩放到 48px canvas），描边色取自面板 item 计算色；个别形状路径异常时降级画矩形轮廓。canvas 元素在 `dragend` 移除。
- 经验：拖拽预览若要用自定义元素，绝不可一开始就离屏；要在屏内捕获再移走，或改用 canvas（canvas 离屏渲染最可靠，但 setDragImage 仍需其在调用时处于"可见捕获"状态）。
- 版本 0.4.4 → 0.4.5；tsc 0 错误、构建 exit 0；产物校验 createDragGhost/setDragImage/Path2D/屏内捕获(clientY) 均存在、旧离屏-only 幽灵已移除。

## 拖拽预览仍带灰底块 —— 三次修复（v0.4.7）——真正根因
- 用户截图：v0.4.6 拖拽时预览仍有一个**淡灰色矩形块**（比 v0.4.4 的深色块浅，但仍在）。
- **真正根因（跨三版都没踩对）**：浏览器在 `dragstart` 触发的**同一帧**就生成拖拽位图，此时源元素已处于 `:active` 状态，在 `dragstart` 回调里加 `.drawio-dragging` 类**来不及参与绘制** → 截到的还是 active 底色。所以必须在**更早的 `mousedown` 阶段**就加透明类（早于位图生成）。
- 修复：`makeShapeDraggable` 改为 `mousedown` 加 `.drawio-dragging`，`mouseup`/`mouseleave`/`dragend` 三处兜底移除；CSS 规则扩展为 `.drawio-dragging` / `:hover` / `:active` 三态组合，并清 `background` + `background-color` + `background-image` + `outline` + `box-shadow` + `transition`（全 `!important`）。
- **可复用结论（拖拽预览通用）**：HTML5 原生拖拽的默认预览 = 截图源元素，位图在 dragstart 同帧生成。想让预览"只显示内容、去掉容器/状态底色"，**透明化必须在 mousedown 或更早就位**；在 dragstart 里改样式一定来不及。`setDragImage` 方案在 Electron 里对离屏元素不捕获、且是惰性捕获，不可靠——优先用"源元素 + 提前透明化"。

## 拖拽预览灰底 —— 最终方案：弃用原生 HTML5 DnD（v0.4.9）
- 背景：v0.4.4~0.4.8 四轮修复（setDragImage 离屏/屏内捕获/canvas/提前透明化）在本 Electron 构建里全部不可靠；v0.4.8（未提交的工作区改动）又退回 setDragImage+离屏 div，用户实测仍是灰底块。
- **最终方案**：`makeShapeDraggable` 彻底改为 **pointer 事件自建拖拽**（pointerdown/move/up/cancel），不再使用 draggable/dragstart/dragover/drop；跟随光标的是 DOM 里的 `.drawio-drag-ghost`（透明 div + 纯 SVG 轮廓，`transform: translate` 定位、光标压中心、`pointer-events:none`）→ 原生拖拽位图机制整个被绕开，灰底问题在原理上消除。
- 关键细节：
  1. **不要 setPointerCapture**：捕获后 pointerup 无论落在哪都会向源元素派生 click，会把"拖到画布"误判成"点击面板项"在画布中心多加图形 → 监听挂 document。
  2. 移动超 4px 阈值才算拖拽，否则留给 click（点击=添加到画布中心）；拖拽结束后置 `suppressPaletteClick` 吞掉落点在面板项上时派生的那一次 click。

  3. 空格平移：keydown（仅 `container.matches(":hover")` 且非输入框、非 `graph.isEditing()` 时接管）→ `panningHandler.useLeftButtonForPanning=true` + `ignoreCell=true`（按在图形上也平移，draw.io 行为）；keyup/blur 恢复。`registerDomEvent` 挂 document/window，视图关闭自动解绑。
